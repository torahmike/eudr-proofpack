# Roadmap Notes

EUDR ProofPack should remain careful with compliance language. Prefer "readiness", "evidence pack", "due-diligence support", and "buyer-ready documentation".

Near-term technical priorities:

- Add real email magic links and signed one-time login tokens.
- Back rate limiting with durable state.
- Replace JSON export with generated PDF summaries.
- Implement ZIP export from R2 documents through the queue consumer.
- Add map polygon support and GeoJSON validation.
- Add role-based team workflows and consultant review states.
